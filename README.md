## About

Antistasi Ultimate Mission Planner helps resistance commanders plan their campaign strategy. Track territory control, manage squad compositions and plan attack and defense operations across the Antistasi persistent campaign.

---

## Features

| Feature | Description |
|---------|-------------|
| **Territory Map** | Track friendly and enemy territory control across the campaign |
| **Squad Builder** | Plan and document squad compositions per operation type |
| **Resource Tracker** | Monitor HR, money and equipment resources across your campaign |
| **Operation Planner** | Plan attack and defense missions with objectives and timing |
